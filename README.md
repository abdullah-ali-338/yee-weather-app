# Glassmorphic Weather Dashboard

A modern, responsive, real-time weather application built using vanilla Web technologies (HTML5, CSS3, JavaScript ES6+) and powered by the Open-Meteo API. Designed with a clean glassmorphic aesthetic featuring frosted glass cards, dynamic ambient gradients, smooth backdrop blurs, and adaptive layouts.

# Key Features

Real-Time Weather Metrics: Fetches current temperature, weather conditions, dynamic condition icons, and wind speed.
Smart Geocoding Search: Integrated autocomplete search querying city coordinates globally with debounce-handled search execution.
7-Day Daily Forecast: Extended multi-day weather outlook displaying high/low temperature metrics and daily weather conditions.
Live Dynamic Clock: Client-side real-time clock and date sync without external time API dependencies.
Zero-Build Lightweight Architecture: Pure client-side application requiring no server-side compilation, build steps, or external framework runtime.

# Tech Stack
Frontend: HTML5, CSS3 (Flexbox/CSS Grid, Backdrop Filters), Modern JavaScript (Fetch API, Async/Await)
API Integration: Open-Meteo Forecast API & Geocoding Search API
Deployment: Hosted live via Vercel / GitHub Pages
